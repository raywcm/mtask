# 扩展语言包

语言包位于 `internal/i18n/locales/*.json`，通过 Go embed 编入单文件程序。程序自动发现并注册语言包；配置校验、语言设置菜单、标题栏、地区识别、TUI 和 CLI 帮助共用注册表，没有分别维护的语言枚举。

当前附带简体中文（zh-CN）、English（en）、日本語（ja）、Español（es）、Français（fr）。auto 不是单独一种语言。

## 新增语言

1. 复制 `en.json` 为新的语言代码文件，例如 `de.json`。
2. 修改元信息：`code` 为 `de`，`name` 为原生名称 `Deutsch`，`order` 控制菜单顺序，`aliases` 可提供额外地区或脚本别名。
3. 翻译 `messages` 和 `cli` 的全部值，保留键、命令名、参数名和快捷键。
4. 执行 `go test ./internal/i18n ./internal/config ./internal/tui ./internal/cli` 并重新构建。新语言自动出现在配置和设置菜单，通常不需要修改 Go 代码。

以下示例展示元信息和部分文案；添加语言时仍需从 `en.json` 复制全部键：

```json
{
  "code": "de",
  "name": "Deutsch",
  "aliases": [],
  "order": 60,
  "messages": {"settings": "Einstellungen"},
  "cli": {"Rename a task": "Aufgabe umbenennen"}
}
```

文件名必须与 code 一致；code 和别名不允许歧义。自动识别规范化大小写、下划线、编码与修饰后缀，以最长匹配选择地区/脚本变体；例如基础语言 `fr` 可识别 `fr_CA.UTF-8`。未来加入更具体的地区包时，具体别名优先。locale 优先级为 LC_ALL → LC_MESSAGES → LANGUAGE → LANG；LANGUAGE 支持冒号分隔的候选列表。

找不到支持的语言时回退英文。单条文案缺失时也回退英文；内置语言包须覆盖英文基准的所有键，由完整性测试检查。时长单位提供单数/复数文案，适用于当前五种语言；新增复杂语法时应同时检查组合后的显示。

系统错误保留原始诊断。用户自己的任务名、目录、命令输出及 JSON 字段名不翻译。嵌入式语言包随新二进制部署，运行时不需要额外文件或网络翻译服务。
