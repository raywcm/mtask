# Language packs

Packs live in `internal/i18n/locales/*.json` and are embedded in the binary.
The registry drives settings, locale detection, TUI messages and CLI help.
Included languages: English, Simplified Chinese, Japanese, Spanish and French.

To add a language:

1. Copy `en.json` to a file named after the locale, such as `de.json`.
2. Set `code`, native `name`, menu `order` and optional `aliases`.
3. Translate all `messages` and `cli` values. Keep keys and command names intact.
4. Run `go test ./internal/i18n ./internal/config ./internal/tui ./internal/cli`,
   then rebuild. The new pack appears automatically.

Filename and code must match; codes and aliases must be unique. Detection uses
LC_ALL → LC_MESSAGES → LANGUAGE → LANG and normalizes case, encoding and region
suffixes. Unsupported languages or missing strings fall back to English.
Built-in packs must cover every English key. Task names, command output, JSON
fields and system errors are not translated.
