# TaskDock v0.7.0

- Move sessions with Shift+Up/Down. Order is saved and shared across frontends.
- Use Ctrl+Up/Down for application arrows in the monitor.
- Keep common shortcuts in the title row, including the monitor entry.
- Join shared control automatically. The oldest controller owns terminal size;
  other monitors follow it, and ownership transfers when it disconnects.
- Keep read-only connections during takeover and return displaced controllers
  to the task list with the broker’s reason.
- Remove unused service and output-pump scaffolding; reuse terminal redraw handling.
- Update the English demo with real Codex and OpenCode alongside shells and servers.

Existing sessions remain running. New frontends also share control with v0.5.2
and v0.6.0 brokers; older brokers retain exclusive attach when necessary.
