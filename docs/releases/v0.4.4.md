First public release of mtask.

- Persistent terminal tasks with CLI and a five-language TUI.
- Reconnect after SSH disconnects; choose exclusive, read-only, shared or takeover connections.
- Monitor tasks, inspect retained output and configure automatic history cleanup.
- Detach with F12, Ctrl+B then d, or Ctrl+B then Ctrl+D. Standalone Ctrl+D remains application input.
- Linux and macOS binaries for amd64/arm64, Linux Deb/RPM packages and a checksum-verifying installer.

Tasks survive frontend exits and binary upgrades, but not host reboots.
Screen restoration requests an application redraw; some programs may need a
manual refresh. See the compatibility notes in the repository.
