# TaskDock v0.6.0

The project is now TaskDock, with command `tdock` and repository
[raywcm/taskdock](https://github.com/raywcm/taskdock).

- Updated CLI, TUI, documentation, demo, installers and package names.
- Existing mtask sessions, settings and history remain available without restarting brokers.
- Fresh installs use `~/.local/state/taskdock`; existing state stays in place.
- Linux/macOS archives for amd64/arm64, plus Linux Deb/RPM packages.

Install with the release installer, then run `tdock`. The old repository URL redirects.
