Control tasks directly in a half pane. Enter or v opens it; new TUI sessions
open selected there. Ordinary Enter stays with the application. Ctrl+Enter opens
fullscreen, Ctrl+F searches sessions, and F12 returns to the list.

Search covers running and stopped sessions by name, ID, directory and command.
Long lists scroll with selection and support page navigation.

Add common tmux session commands and flags: new-session/new (-s, -c, -d, -A),
list-sessions/ls, attach-session/attach/a (-t, -r), rename-session/rename,
has-session/has and kill-session. Stop retains history; kill-session removes it.
Replace list/status/rm with ls/show/delete and new -n with new -s. Show always
prints JSON. See docs/usage.md for quoting rules and the supported subset.

Existing tasks keep their processes during upgrades. Fullscreen attach retains
its original terminal path; the embedded view supports keyboard control.

Fix a macOS fullscreen attach busy loop: poll reported POLLNVAL for /dev/tty,
then repeated reads returned EAGAIN. Use select on macOS and validate poll events
on Linux. Add real-PTY idle CPU checks for all connection views.
