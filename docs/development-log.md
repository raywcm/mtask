## 2026-10-28 — 0.4.3-dev

### 修复

- 修复 TUI 收到 SIGINT 后在原命令行打印 `MTasK: program was killed: program was interrupted` 的问题。
- 进程信号统一由 main 处理，TUI 将取消请求转换为正常退出。退出前清空备用屏幕，随后恢复原命令行、光标和 termios。
- 避开 Bubble Tea 的强制退出路径，等待输入读取结束后再关闭，修复中断时的读取/Close 竞态。
- 状态加载、历史读取和监控连接在正常退出和错误返回时均会回收。
- 测试回收进程时持续排空 PTY，避免尾部输出填满缓冲造成假死。启动与返回列表改为等待实际输出，不再依赖固定延时。

### 工程

- 模块路径改为 `github.com/raywcm/mtask`，建立私有 Git 仓库。
- 采用 MIT 许可证；归档和 Deb/RPM 包包含项目许可证及 25 个运行依赖的许可证原文。
- 增加 `third_party_notices.py --check`，在依赖变化后检查声明文件是否需要更新。
- `make build` 先写临时文件，再原子替换程序。
- 增加中英文首页、Shell 操作演示、兼容性表和统一测试入口 `make acceptance`。
- GitHub Actions 运行结果见 [Actions](https://github.com/raywcm/mtask/actions)。尚未发布 Release 或 APT 软件源。

## 2026-10-28 — 0.4.0-dev

## 2026-10-27 — 0.3.0-dev

- 增加接管、只读、共享三种连接方式。默认 Enter 和无选项 attach 仍使用独占连接。
- TUI 按 `c` 选择连接方式；遇到 busy 时打开同一菜单，默认只读。CLI 增加互斥选项 `--takeover`、`--read-only`、`--shared`。
- Hub 改为多个有界输出订阅，每连接约 2 MiB 队列，慢客户端单独断开。
- Broker 拒绝只读连接的 Input/Resize/Stop。接管断开所有控制端，保留只读端；共享连接按帧串行写入 PTY。
- 最早加入且仍在线的控制端决定 PTY 尺寸，离开后按顺序转交；只读端不自动提升。
- 协议 v1 增加可选能力字段和 Notice 帧。新前端先探测能力，再请求非默认连接方式，避免旧 Broker 将只读请求当作普通可写连接。
- 新旁观端通过主控协作重绘。普通 Shell 的既有滚动历史不复制到新终端。

race 单测、多连接真实 PTY、五语言菜单、只读权限、尺寸主控和全屏重绘测试通过。与 0.2.8 前后端的双向兼容测试通过。此版本先在 macOS 运行，Linux 为交叉构建；Ubuntu 实机测试从 0.4.0 开始覆盖这些功能。

尺寸测试使用 Ping/Pong 屏障确认 Resize 已处理，避免跨连接查询的时序不确定。

## 2026-10-27 — 0.1.1-dev

## 2026-10-27 — 0.1.0-dev

### 基础架构（A0）

建立每任务独立 Broker 的进程模型，定义 task、protocol、broker、ptyprocess、store、terminal、service 和 CLI/TUI 边界。完成帧编解码、单控制端 Hub、真实 PTY 原语、原子快照、Raw Mode 恢复和列表骨架。

macOS arm64 的单元、race 和真实 PTY 测试通过，四目标交叉构建通过。协议 fuzz 约两秒执行 742,560 次，无失败。macOS 的非阻塞 PTY 使用复制 FD 重新包装到 Go poller 的方式处理。初始设计保存在 [架构存档](archive/architecture-a0.md)和[协议存档](archive/protocol-a0.md)。

### 后台管理（A1–A5）

完成 detached launcher、readiness pipe、私有 Unix Socket、双向 UID 验证、实例握手、进程会话清理、退出码、有界日志和 CLI/TUI 管理操作。增加目录锁、名称竞争保护、元数据大小限制和原子安装器，配置 GoReleaser、nFPM 与 CI。

- macOS `/dev/tty` 使用 native poll，读取取消后等待结束，再恢复 termios。
- 主动 detach 先确定本地结果，再关闭 Socket，避免 EOF 竞争改变退出码。
- 首次前台连接保留最多 2 MiB 启动输出；快速退出应用显示输出并返回原退出码。
- `stop` 等待 Broker 锁释放后返回，避免紧接着删除时发生竞争。
- 状态目录先规范化，避免 `/var` 与 `/private/var` 等路径别名生成不同 Socket 哈希。

验证包括 argv 原样传递、控制序列和二进制字节、SIGWINCH、Ctrl+C、Shell job 清理、忽略 TERM 后 KILL、Broker 崩溃恢复、16 任务并发和名称竞争、18 MiB 日志轮转、12 MiB 慢客户端输出、Bash/Vim 交互及原子升级。

32 个任务连续观察 60 秒，219 次完整健康扫描通过；Broker RSS 总量 263200 → 203728 KiB。四份 tar.gz、两份 Deb、两份 RPM、SHA-256 和本地 APT 索引检查通过。该阶段的运行测试在 macOS ARM64 上完成，Ubuntu 实机记录从 0.2.7 开始。
