# Initial protocol draft (A0)

Historical draft, 2026-10-27. See [protocol v1](../protocol.md).

The prototype defined the MT/version/kind/length frame header, raw Input/Output
payloads, JSON control messages and bounded short-read/write handling. Socket
handshakes and message semantics were implemented in the next stage. Later v1
extensions added optional capability fields and Notice for multi-client control.
